Claude Code Skills

在 Claude Code 中使用以下指令进行报表开发：

cpt-knowledge
知识库加载

加载帆软 CPT 知识库，理解 XML 标签结构、控件类型、样式系统。首次对话时自动触发。

cpt-create
报表创建

根据数据源、筛选条件、展示列信息，从零生成完整的 .cpt 报表文件。

cpt-modify
报表修改

基于现有 .cpt 模板，增删筛选组件、数据列、数据源参数，自动调整布局。

cpt-validate
报表验证

验证 .cpt 文件是否符合帆软规范：XML 结构、参数绑定、样式索引、CDATA 格式。
