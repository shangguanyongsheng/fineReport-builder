## 二、报表生成流程

### 2.1 完整流程图

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              报表生成流程                                    │
└─────────────────────────────────────────────────────────────────────────────┘

用户操作                              系统处理
────────                              ────────

┌─────────────┐
│ 1. 打开界面 │
│  /excel-    │
│  convert-v3 │
└──────┬──────┘
       │
       ▼
┌─────────────┐     ┌──────────────────────────────────────────────────────┐
│ 2. 配置     │     │ 前端数据收集 (collectConfig)                          │
│  - 数据源   │ ──► │ - datasource: {type, class_name, parameter_template} │
│  - 列映射   │     │ - column_mapping: {A: {header, field}}               │
│  - 筛选组件 │     │ - filter_components: [{label, code, type}]           │
│  - 样式     │     │ - styles: [...]                                      │
└──────┬──────┘     └────────────────────────┬─────────────────────────────┘
       │                                      │
       ▼                                      ▼
┌─────────────┐     ┌──────────────────────────────────────────────────────┐
│ 3. 点击     │     │ POST /api/v2/generate                                 │
│  "生成报表" │ ──► │ 请求体: JSON 配置                                     │
└──────┬──────┘     └────────────────────────┬─────────────────────────────┘
       │                                      │
       │                                      ▼
       │             ┌──────────────────────────────────────────────────────┐
       │             │ Step 1: 参数处理                                      │
       │             │ - Class 数据源: 自动从 filter_components 推断参数    │
       │             │ - DB 数据源: 从 SQL 提取 ${param} 参数               │
       │             └────────────────────────┬─────────────────────────────┘
       │                                        │
       │                                        ▼
       │             ┌──────────────────────────────────────────────────────┐
       │             │ Step 2: 构建配置 (cpt_config)                         │
       │             │ - data_sources: [{name, type, parameters, ...}]      │
       │             │ - filter_controls: [{name, label, type, ...}]       │
       │             │ - cells: [{column, row, value, style_index}]        │
       │             │ - styles: [{name, background, border, ...}]         │
       │             └────────────────────────┬─────────────────────────────┘
       │                                        │
       │                                        ▼
       │             ┌──────────────────────────────────────────────────────┐
       │             │ Step 3: 生成 XML (CPTGenerator.generate)             │
       │             │                                                       │
       │             │  ┌─────────────────────────────────────────────┐    │
       │             │  │ WorkBook                                     │    │
       │             │  │ ├── TableDataMap        ← 数据源映射         │    │
       │             │  │ ├── ReportWebAttr       ← 标题              │    │
       │             │  │ ├── Report              ← 报表主体           │    │
       │             │  │ │   ├── CellElementList ← 单元格列表        │    │
       │             │  │ │   └── ...                                 │    │
       │             │  │ ├── ReportParameterAttr ← 参数面板          │    │
       │             │  │ └── StyleList           ← 样式列表          │    │
       │             │  └─────────────────────────────────────────────┘    │
       │             │                                                       │
       │             │ 关键处理:                                              │
       │             │ - <O> 标签使用 CDATA 格式                             │
       │             │ - FineColor 添加 hor/ver 属性                        │
       │             │ - ClassTableData 必须有 Parameters 节点              │
       │             └────────────────────────┬─────────────────────────────┘
       │                                        │
       │                                        ▼
       │             ┌──────────────────────────────────────────────────────┐
       │             │ Step 4: 保存文件                                       │
       │             │ - 文件名: {title}_{timestamp}.cpt                     │
       │             │ - 路径: outputs/{filename}                            │
       │             └────────────────────────┬─────────────────────────────┘
       │                                        │
       ▼                                        ▼
┌─────────────┐     ┌──────────────────────────────────────────────────────┐
│ 4. 下载     │ ◄─ │ 返回响应                                               │
│  .cpt 文件  │     │ {success: true, download_url: "/api/download/..."}   │
└─────────────┘     └──────────────────────────────────────────────────────┘
```

## 五、文件结构

```
fineReport-builder/
│
├── web/
│   ├── app.py                    # Web 服务入口
│   └── templates/
│       └── excel_convert_v3.html  # V3 界面
│
├── parsers/
│   ├── cpt_generator.py          # ⭐ 核心生成器
│   ├── cpt_parser.py             # CPT 解析器
│   ├── excel_parser.py           # Excel 解析器
│   └── class_table_data.py       # ClassTableData 解析
│
├── templates/
│   ├── FinanceCreditContractAnalysis.cpt      # 管理分析模板
│   ├── FinanceCreditContractAnalysisDetail.cpt # 明细模板 (examples/)
│   ├── CPT_TEMPLATE_ANNOTATION.md             # 模板标注
│   └── target/                                # 目标目录
│
├── examples/
│   └── FinanceCreditContractAnalysisDetail.cpt # 明细报表模板
│
├── outputs/                      # 生成的报表输出
├── uploads/                      # 上传的文件
├── logs/                         # 日志目录
└── memory/                       # Agent 记忆系统
```

## 六、快速定位指南

| 问题类型 | 检查文件 | 关键代码位置 |
|----------|----------|--------------|
| 参数为空 | `web/app.py` | `generate_report_v2()` 函数，参数推断逻辑 |
| CDATA 格式 | `parsers/cpt_generator.py` | `_prettify()` 方法 |
| 样式不显示 | `parsers/cpt_generator.py` | `_create_style_element()` 方法 |
| 控件位置错 | `parsers/cpt_generator.py` | `_generate_parameter_attr()` 方法 |
| 数据绑定错 | `parsers/cpt_generator.py` | `_generate_cell()` 方法 |
